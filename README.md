# Documento de Especificación de Requisitos - Prototipado CRM + ERP para Emprendedores

## 1. Actores Principales del Sistema

1. **Admin:**  Usuario encargado de administrar y controlar el sistema. Tiene acceso al 100% de los módulos y funcionalidades de la aplicación y cuenta con permisos para gestionar los usuarios mediante las operaciones
2. **Socio** Usuario del emprendimiento que participa en la gestión de los diferentes procesos y proyectos del negocio.
3. **Comercial:** Usuario encargado de gestionar la relación con los clientes y los procesos comerciales del emprendimiento. Tiene acceso al módulo CRM para administrar clientes, realizar seguimiento de oportunidades y gestionar las actividades comerciales.
4.  **Contador:** Usuario encargado de gestionar los procesos financieros y contables del emprendimiento. Tiene acceso al módulo ERP para registrar, consultar y gestionar la información financiera y administrativa del negocio.
5.  **Vendedor:** Usuario encargado de apoyar el proceso de ventas mediante la elaboración y gestión de cotizaciones. Tiene acceso al módulo de Cotización, perteneciente al CRM, para gestionar las cotizaciones de productos o servicios ofrecidos a los clientes.

## 2. Matriz de Transformación: Problemas, Necesidades y Requisitos Funcionales

| # | Problema Identificado | Necesidad de Software | Requisito Funcional |
| :-: | :--- | :--- | :--- |
| *1* | Desconexión entre los socios del emprendimiento y falta de un sistema compacto y modular que les permita administrar sus cuentas y proyectos de manera rápida y síncrona. | Centralizar la información de los socios, cuentas y proyectos en una plataforma modular que facilite el acceso y la gestión conjunta de la información del emprendimiento. | El sistema debe permitir a los socios acceder y gestionar de forma centralizada sus cuentas, proyectos y procesos, de acuerdo con los permisos establecidos para cada usuario. |
| *2* | Pérdida de seguimiento paralelo en proyectos administrados por separado dentro del emprendimiento. | Centralizar la información de los proyectos para facilitar su seguimiento, organización y control desde un único sistema. | El sistema debe permitir crear, consultar, actualizar y realizar seguimiento a los proyectos, sus actividades, responsables, estados y avances. |
| *3* | Uso de hojas de cálculo y documentos para registrar actividades y finanzas de los emprendedores. | Digitalizar y centralizar el registro de las actividades comerciales, financieras y administrativas del emprendimiento. | El sistema debe permitir registrar, consultar, actualizar y gestionar digitalmente la información de clientes, actividades, cotizaciones y procesos financieros y administrativos mediante los módulos CRM y ERP. |
